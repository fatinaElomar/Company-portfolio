An ultra-luxury, high-converting agency portfolio website built for **Media Mined** — specialized in scaling social media brands, viral content, and high-performance **Shopify** storefronts.


## 🌐 Deployment Options

The project is completely configured and ready for 1-click deployment:

### Option 1: Vercel (Recommended)
1. Install Vercel CLI (or connect GitHub repository on [vercel.com](https://vercel.com)):
   ```bash
   npx vercel
   ```
2. Follow the prompt (`vercel.json` is already configured for instant routing).

### Option 2: Netlify
1. Run:
   ```bash
   npx netlify deploy --prod
   ```
2. Or drag-and-drop the `dist` folder directly onto [app.netlify.com/drop](https://app.netlify.com/drop). (`netlify.toml` is pre-configured).

### Option 3: GitHub Pages
1. Push this repository to GitHub:
   ```bash
   git remote add origin https://github.com/<your-username>/media-mined.git
   git branch -M main
   git push -u origin main
   ```
2. Enable GitHub Pages in your repo Settings -> Pages -> Deploy from a branch (or configure GitHub Actions).
